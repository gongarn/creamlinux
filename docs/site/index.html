🐨 creamlinux

Разблокировка DLC в нативных Linux-играх Steam — обновлённый форк CreamAPI

Что это

Инструмент заставляет игру считать, что все DLC установлены. Файлы DLC должны лежать в папке игры — анлокер их не скачивает. Работает с нативными Linux-играми (Proton/Wine — через SmokeAPI, см. инструменты).

Возможности

  • ⚡ Режим «всё сразу» (unlockall) — без списков ID
  • 🎮 Поддержка свежих версий Steam SDK (SteamApps v009, SteamUser v023, SteamClient v023)
  • 🖥️ Веб-интерфейс: список игр, установка в один клик, живой лог
  • 🔌 Единый установщик для native и Proton игр (SmokeAPI, режимы hook/koaloader/proxy)
  • 🔄 Автообновление списков DLC из Steam Store и с апстрима

Быстрый старт

1. Скачай релиз и распакуй в папку игры, либо запусти веб-интерфейс:

python3 tools/gui.py

2. В настройках запуска игры в Steam укажи:

sh ./cream.sh %command%

⚠️ Файлы DLC (например, папка dlc) нужны отдельно — анлокер не скачивает контент.
